# Identidade visual

Os arquivos oficiais utilizados pelo aplicativo são:

- `assets/branding/agrocontrol_logo.png` — logotipo horizontal fornecido pelo proprietário.
- `assets/branding/agrocontrol_mark.png` — símbolo/ícone fornecido pelo proprietário.
- `web/favicon.png` — mesmo símbolo oficial usado como favicon e ícone do PWA.

A interface usa os PNGs originais com transparência, sem redesenho ou substituição por versões aproximadas.
